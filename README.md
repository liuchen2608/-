# 大象阿宝

大象阿宝是一款面向普通成年人的健康生活助手。用户输入一个日常生活问题后，产品围绕饮食、作息、运动和习惯给出温和、可执行的建议，并尽量把第一步收敛到今天就能完成的一件小事。

项目不提供诊断、病因判断、治疗方案、药品推荐、检查报告解读或其他医疗服务。命中前置医疗/紧急规则的请求直接使用固定回复，不发送给模型。规则无法覆盖所有表达；模型还会遵循范围限制，返回内容经过后置检查，但不能保证识别所有风险。

## 主要功能

- 生活需求对话：经使用者授权后，通过 DeepSeek 自然回应、理解需求、少量追问，再结合前文给出生活方式建议。
- 权威资料 RAG：服务端先从内置的只读健康生活知识库检索相关片段，再交给 DeepSeek 生成；页面展示本条回答实际引用的官方来源。
- 生活偏好：保存起床和入睡时间、饮食习惯、运动经验、可用时间及生活目标。
- 习惯计划：创建饮食、作息、运动或日常习惯计划，并手动记录当天完成情况。
- 建议记录：按关键词查找并继续查看历史对话。
- 反馈与隐私：反馈建议是否有帮助、是否难执行；授权或撤回第三方 AI 处理；删除账号数据。
- 双重内容边界：模型调用前进行请求分类，模型返回后再次检查输出；边界请求直接使用本地固定回复。

对话输入处理：普通问候、意图不明确和简短补充都可以进入 DeepSeek 多轮交流。服务端附带当前用户当前生活对话最近最多 12 条可用消息（完整问答对、总计不超过 8000 字符）、筛选后的主动生活偏好，以及本轮检索出的公开知识片段；不附带账号身份、旧医疗档案或其他对话。旧版排序授权不适用于原文发送，必须重新取得 `external_ai_conversation_v1` 授权。历史中旧版回复、拦截和本地降级轮次不作为模型上下文。

RAG 语料来自 WHO、国家卫生健康委、中国疾控中心、CDC、HHS 和 NIH/NIDDK 等官方来源，当前覆盖健康饮食、睡眠作息、身体活动和习惯改变。检索在服务端本地完成，不保存或索引用户输入；模型只返回来源 ID，链接由服务端白名单映射，避免模型编造网址。医疗与紧急请求会在检索和模型调用前被拦截。完整来源核验、适用范围及易错点见 [RAG 权威来源研究](docs/rag-source-research.md)。

页面区分“DeepSeek 回复”和本地回复。缺少密钥、限流、余额/鉴权错误、18 秒超时、回复格式或内容检查失败时，明确显示未连接及本地回复，不伪装成 DeepSeek 成功。

## 技术栈

- React 19、TypeScript、vinext
- Cloudflare Workers / OpenAI Sites 托管
- Cloudflare D1、Drizzle ORM
- 本地确定性 RAG 检索 + DeepSeek Chat Completions API（仅在用户授权后用于生成生活建议）
- Node.js 内置测试运行器、ESLint

## 本地启动

需要 Node.js `>=22.13.0`。

```bash
npm ci
npm run dev
```

生产环境通过 Sites 服务端秘密变量配置 `DEEPSEEK_API_KEY`，可用 `DEEPSEEK_MODEL` 覆盖默认 `deepseek-v4-pro`。本地 Workers 运行时可使用已忽略的 `.dev.vars` 配置同名变量；不要将密钥粘贴进页面、聊天或提交到仓库。未配置、调用失败或使用者未授权时，系统会返回明确标记的本地回复。

对接依据：[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/) 与 [Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)。单次请求携带多轮 `messages`，使用 JSON 输出并显式关闭思考模式；只展示经过校验的回复，不展示推理内容。

```bash
npm run lint
npm test
npm run build
```
