# 大象阿宝 Android 手机版

这是“大象阿宝”的独立 Android 手机应用。对话、习惯计划、完成状态和闹钟任务都在安装包内运行并保存在当前手机，不再加载 `chatgpt.site`。应用通过系统 `AlarmClock` 创建闹钟，不读取闹钟列表。DeepSeek 是可选能力，由用户在手机设置页自行填写密钥；密钥保存在应用私有空间，不写入安装包。

## 行为

- `operation=set`：打开系统新建闹钟页面，带入小时、分钟和任务标题，由用户确认保存。
- `operation=show`：打开系统闹钟列表。Android 没有可靠的跨厂商“按网页任务删除闹钟”接口，因此关闭开关或删除任务后，需要用户在系统闹钟中确认删除。
- 没有明确时间的任务不会创建闹钟。
- 直接启动应用：进入本地交互主页，可对话、确认加入计划、打卡、删除任务、连接系统闹钟和查看系统闹钟。
- 未配置 DeepSeek 时使用内置的生活方式建议；配置后才会把对话内容直接发送给 DeepSeek。
- 卸载应用会清除本地对话、计划和手机端保存的 DeepSeek 密钥。

## 构建

使用 JDK 17、Android SDK 35 和 Gradle 8.9：

```bash
./gradlew :app:assembleDebug
```

当前发布文件使用英文版本名 `daxiang-abao-mobile-xiaomi12spro-v1.2.0.apk`，同时复制为网站内部稳定资源 `public/downloads/daxiang-abao-alarm.apk`。对外下载路由应返回版本化英文文件名，避免与手机里的旧下载同名后被浏览器保存成 `.apk.1`。

如果手机已安装早期测试版，请先卸载旧版再安装 `1.2.0`。本次独立手机版使用了新的测试签名，Android 不允许不同签名的 APK 直接覆盖安装。
